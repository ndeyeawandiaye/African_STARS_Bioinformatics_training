Is this genome good enough?

30 min

Goal: For each sample, gather the quality metrics in one table and make a decision: is the genome usable for phylogenetics (Day 4), does it need review or re-sequencing, or should it be excluded?

A genome is not simply “good” or “bad”: it is good enough for a specific purpose, based on several quality metrics.

The numbers that matter

Metric Why it matters
Total reads / % mapped Indicates the amount of sequencing data and the proportion mapping to the virus. A low mapping rate may indicate contamination or poor enrichment.
Mean depth Indicates the average sequencing coverage at each reference position.
% of genome at ≥ 10× depth Measures how much of the genome has sufficient coverage for reliable consensus calling.
% N / longest run of Ns Indicates missing sequence information. Long runs of Ns may correspond to missing genomic regions.
Negative control (NTC) Checks whether viral reads are detected in a sample that should contain no viral material.

Step 1 — Build the summary table

The following commands collect the metrics for each sample using the outputs generated in previous exercises.

mkdir -p results

printf "sample\ttotal_reads\tpct_mapped\tmean_depth\tpct_ge10x\tN_bases\tpct_N\tlongest_N_run\n" \
  > results/qc_summary.tsv

for s in S01 S02 S03 S04 S05; do
  bam="results/bam/${s}.bam"
  depth="results/coverage/${s}.depth.tsv"
  fasta="results/consensus/${s}.fa"

  total=$(samtools view -c -F 2304 "$bam")
  mapped=$(samtools view -c -F 2308 "$bam")

  pm=$(awk -v m="$mapped" -v t="$total" \
    'BEGIN {if (t>0) printf "%.1f",100*m/t; else print "NA"}')

  read -r dp ge10x < <(
    awk '{
      t += $3
      if ($3 >= 10) n++
      i++
    } END {
      if (i>0) printf "%.1f %.1f",t/i,100*n/i
      else print "NA NA"
    }' "$depth"
  )

  nb=$(grep -v '^>' "$fasta" | tr -d '\n' | tr -cd 'Nn' | wc -c | tr -d ' ')

  genome_length=$(grep -v '^>' "$fasta" | tr -d '\n' | wc -c | tr -d ' ')
  pct_n=$(awk -v n="$nb" -v l="$genome_length" \
    'BEGIN {if (l>0) printf "%.1f",100*n/l; else print "NA"}')

  run=$(grep -v '^>' "$fasta" | tr -d '\n' |
    grep -oE '[Nn]+' | awk '{if(length>$1) max=length} END {print max+0}')

  printf "%s\t%s\t%s\t%s\t%s\t%s\t%s\t%s\n" \
    "$s" "$total" "$pm" "$dp" "$ge10x" "$nb" "$pct_n" "$run" \
    >> results/qc_summary.tsv
done

column -t -s $'\t' results/qc_summary.tsv

Important: This example assumes the BAM, depth and consensus files follow the paths shown above. Adapt the filenames if your workflow uses a different naming convention. The negative control should be evaluated separately from patient samples.

Cross-check: Compare your results with precomputed/qc_summary.tsv, which contains the expected metrics and a PASS / REVIEW / FAIL classification.

Step 2 — Decide what to do with each sample

These are illustrative thresholds, not universal standards. Adapt them to the sequencing protocol and intended analysis.

Criterion Good To review Poor
% mapped ≥ 90% 70–89.9% < 70%
Genome at ≥ 10× ≥ 90% 70–89.9% < 70%
% N ≤ 10% > 10–20% > 20%
Negative control No concerning viral signal Investigate low-level signal Clear evidence of contamination

Step 3 — Discussion questions

1. Which sample would you re-sequence, and what would you change?

TipAnswer
  • S03: Investigate the low read count and repeat the extraction or library preparation if needed. Increase sequencing depth if insufficient read allocation is the cause.
  • S02: Investigate the missing region. If amplicon dropout is confirmed, re-amplify the affected region, inspect primer-binding sites and consider redesigning the primers.
  • S04: Investigate why only 75% of reads map to the reference. Check read quality, possible contamination and off-target sequences before deciding whether re-sequencing is necessary.

2. What should you report about the negative control?

TipAnswer

Report the total number of reads, the number and proportion mapping to the virus, and any evidence of contamination. Investigate possible sources such as barcode cross-talk, carry-over contamination or contaminated reagents.

Do not automatically conclude that other samples are unaffected. Assess whether the control signal could compromise the results, especially for samples with low viral read counts.

3. Which thresholds would you set for your own laboratory?

TipAnswer

Thresholds depend on the intended application:

  • Lineage assignment: may tolerate some missing sequence if lineage-defining positions are covered.
  • Phylogenetics and transmission analysis: generally requires high genome completeness, adequate depth and careful assessment of ambiguous positions.
  • Negative controls: define an acceptable background signal and investigate unexpected viral reads.

Document the thresholds, test them using known samples and replicates, and apply them consistently across sequencing runs.
