Suggested workflow

Module 5 — capstone

Follow the steps in order; each command is independent, copy and paste them one at a time. Adapt freely. Every step ends with a checkpoint question.

1. Quality filter

How much of each outbreak genome is missing (N)?

awk '/^>/{if(name) printf "%s\t%.1f%%\n", name, 100*n/len; name=substr($0,2); n=0; len=0; next} {n+=gsub(/N/,"N"); len+=length($0)} END{printf "%s\t%.1f%%\n", name, 100*n/len}' data/outbreak/sequences.fasta | sort -k2 -n -r | head -5

Remove the genomes above 10 % N (here one), and build the dataset with the reference and S01:

mkdir -p results/outbreak
sed 's/^>.*/>TOYV1_ref/' data/reference/TOYV1.fasta > results/outbreak/all.fasta
seqkit grep -v -p OB24 data/outbreak/sequences.fasta >> results/outbreak/all.fasta
cat results/consensus/S01.fa >> results/outbreak/all.fasta
grep -c '>' results/outbreak/all.fasta
TipCheckpoint

OB24 has 23 % N and is the only genome above the threshold: excluded. The dataset has 28 sequences (1 reference + 26 outbreak + S01).

2. Align and assign lineages

mafft --auto --preservecase --thread 2 results/outbreak/all.fasta > results/outbreak/aln.fasta
python3 scripts/13_lineage.py results/outbreak/aln.fasta --out results/outbreak/lineages.tsv

(Plan B without MAFFT: python3 scripts/11b_align_fallback.py, which uses OB24 too; ignore it or remove it afterwards.)

TipCheckpoint

S01 = TV.2. The other genomes fall in TV.1 (3), TV.3 (5), TV.2 (4), TV.2.1 (8), TV.2.2 (6, without OB24).

3. Tree

iqtree2 -s results/outbreak/aln.fasta -m MFP -B 1000 -T 2 --seed 1 -o TOYV1_ref --prefix results/outbreak/tree -redo
python3 scripts/14_plot_tree.py results/outbreak/tree.treefile --lineages results/outbreak/lineages.tsv --color region --out results/outbreak/tree_region.png

(Plan B: precomputed/phylo/tree.nwk and tree_region.png.)

4. Genomics next to epidemiology

Sort the genomes by date and look at each lineage’s first appearance, place and time:

join -t $'\t' <(sort -k1,1 results/outbreak/lineages.tsv) <(sort -k1,1 data/outbreak/metadata.tsv) | cut -f1,2,4,5 | sort -t$'\t' -k3,3 | column -t -s $'\t'

Questions: when and where does each lineage first appear? Is any genome out of place (a lineage in an unexpected region)?

TipCheckpoint

TV.1 (Jan–Feb, Regions B and D) → TV.3 (Feb–Mar, Region B) → TV.2 first in Region A on 1–5 March → TV.2.1 in Region A (from 20 March) and TV.2.2 in Region C (from 25 March). Out of place: OB22 (TV.2) in Region C on 12 March, and OB14 (TV.2.1) in Region C on 2 April.

5. How far apart are Region C and Region A genomes?

python3 scripts/15_snp_matrix.py results/outbreak/aln.fasta --out results/outbreak/snp_matrix.tsv --ids S01,OB10,OB22,OB14,OB08,OB07,OB23,OB03
column -t results/outbreak/snp_matrix.tsv
TipCheckpoint

OB22 (Region C, TV.2) is only 1 SNP from OB10 (Region A, early March) and 3 from S01: same early genotype in both regions. The TV.2.2 genomes (OB08, OB07; Region C) are 2 SNPs from each other and 4 from the early TV.2 group. OB14 (Region C, TV.2.1) is 4 SNPs from OB23 (Region A, TV.2.1) but 10 from the Region C TV.2.2 cluster: it is linked to the Region A expansion, not to the local Region C cluster. OB03 (TV.3, Region B) is far from all of them (16 SNPs or more).
